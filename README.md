# 🌡️ Termómetro Lector · Jalisco LEO

Herramienta de diagnóstico de la situación lectora de una escuela.
Parte de la **Estrategia Estatal de Lectura, Escritura y Oralidad Jalisco LEO**.

---

## 📋 ¿Qué es?

El **Termómetro Lector** es un wizard de 6 secciones + Acta de Diagnóstico que permite:

1. **Identificar** la escuela y su contexto.
2. **Comparar** los resultados de la escuela con la referencia estatal (Jalisco Avanza 2025).
3. **Integrar** el diagnóstico SAAL (opcional).
4. **Escuchar** las voces del ecosistema (estudiantes, familias, docentes).
5. **Visualizar** el semáforo de 18 dimensiones.
6. **Recomendar** rutas LEO según las necesidades detectadas.
7. **Generar** un Acta de Diagnóstico descargable en PDF/HTML.

El Termómetro **no es un fin**. Es el insumo para la **Hoja de Ruta Trimestral** (Momento 3).

---

## 🚀 ¿Cómo se usa?

### Opción 1: Uso local

1. Descarga la carpeta `termometro-lector/`.
2. Abre `index.html` en cualquier navegador (Chrome, Edge, Firefox, Safari).
3. Llena el wizard paso a paso.
4. Al final, exporta el Acta como PDF o HTML.

**No requiere internet** (excepto para cargar las fuentes y Font Awesome la primera vez).

### Opción 2: GitHub Pages

1. Sube la carpeta a un repositorio de GitHub.
2. Ve a **Settings → Pages**.
3. En **Source**, selecciona `main` y `/ (root)`.
4. Guarda. GitHub te dará una URL tipo:
   `https://tu-usuario.github.io/termometro-lector/`
5. Comparte esa URL con quien necesite usar el Termómetro.
